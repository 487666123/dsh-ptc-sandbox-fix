# PTC 沙箱参数修复

适用于 DeepSeek Harness 0.2.2-rc.5 内置的「PTC 模式」。从插件页面添加本目录后，使用官方的「PTC 模式」即可。

- 模型请求生成前，按会话的沙箱模式和审批策略调整外层 `run_code` 的工具定义。没有可用升级目标时，隐藏 `sandbox_permissions` 和 `justification`。有可用目标时，权限枚举只显示可申请的目标。
- 执行前，如果两个字段成对出现，且请求的已知目标等于当前模式或低于当前模式，则成对移除，再按会话权限运行。真正更宽的请求仍由 DSH 校验理由并执行原有审批流程。缺失字段、无效 JSON 和未知权限值交给 DSH 校验。
- 在受限会话中关闭审批时，工具定义会隐藏升级参数。已经提交的更宽权限请求仍由 DSH 拒绝。
- 模型消息保留原始调用。工具执行记录使用提交给官方执行器的实际参数。

插件通过官方 Bundle 注册。在 PTC 会话开始一轮对话时，插件通过作用域工具执行器接口包装该会话选中的官方执行器。工具列表来自内置预设，调度、沙箱、审批和环境重置由官方执行器负责。

从 1.0.0 更新时，重启 DeepSeek Harness 以加载插件文件。随后，新建会话并选择「PTC 模式」。
